# spring-boot-starter-job（已從倉庫移除）

> 當前 `spring-boot-starter-module` 聚合中**不再包含**獨立的 `spring-boot-starter-job` 模塊。若項目仍需 XXL-Job 等定時任務能力，請在業務 runner 中自行引入對應依賴並配置，或參考歷史版本倉庫。

定時任務集成説明曾位於本頁；新部署請以 `tg-boot` 倉庫 `pom.xml` 與實際模塊列表為準。
