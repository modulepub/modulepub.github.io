明星项目

约 1750 字大约 6 分钟

SHOWCASE · REPLICABLE, NOT JUST IMPRESSIVE

这里的“明星”不以估值、流量或融资额为标准，而以结构是否可复制为标准。 一个项目如果能把目标拆成成果、把成果拆成任务、把每一笔钱记清楚，它就有机会从样板变成方法。

数据说明

以下项目与数字来自产品原型中的演示数据，用于说明项目树、票据份额与财务口径。 它们不代表真实融资、真实经营业绩或任何收益承诺。

这些页面结构、项目树与链上面板，参考自社区 uni-app 工程（uniapp-project）中的 路演中心、任务大厅、白皮书、票据转让与 GCC 工作台。技术实现服务于一个目标： 让项目的目标、任务、资金与治理关系可以被同一个界面读懂。

一、四个样板

01 · 农业 / 溯源 / 共治

青禾智慧农场

县域农产品溯源与社区团购闭环，本季路演聚焦冷链共建。项目树完整展示了“目标 → 成果 → 任务”的三层结构。

冷链共建→县域冷链仓→仓租 / 制冷设备

演示口径：总投入 128 万元 · 640 票 · 已产生收入 35.6 万元 · 28 名共建者 · 72% 份额已分配。

02 · 婚恋 / 轻公益

卿卿轻公益撮合

婚恋撮合服务共建池，红娘助力与嘉宾服务收入按份额公开分账，合规档案与隐私分级是前置条件。

撮合服务池→成功配对→红娘排班 / 场地

演示口径：总投入 86 万元 · 430 票 · 已产生收入 51.2 万元 · 46 名共建者 · 88% 份额已分配。

03 · 能源 / ESG / 已结算

海风新能源微网

园区分布式储能与峰谷套利，结算批次对全体持票人公示。它展示了“重资产项目如何把结果公开到批次”。

储能投运→储能容量→电芯采购 / 安装调试

演示口径：总投入 560 万元 · 2,800 票 · 已产生收入 192 万元 · 21 名共建者 · 份额分配 100%。

04 · 教育 / 共识 / 低门槛

共识学堂共创

共识学会课程与线下共创活动，学费与赞助收入透明入账。它把“知识生产”拆成可计量的课程、场地与导师任务。

课程共创→共创营→场地 / 导师酬金

演示口径：总投入 41 万元 · 205 票 · 已产生收入 26.7 万元 · 58 名共建者 · 76% 份额已分配。

还有一类：高频、轻量的社区商业

原型中还有“拾光咖啡联盟”“邻里互助社”“织造工坊联营”等项目。它们共同说明：

  • 社区项目不必都是“硬科技”；
  • 小体量项目也可以通过透明的票据与任务结构建立信任；
  • “明星”不等于“最大”，而是“结构最清楚、最容易被复制”。

二、五个共同点

1. 目标可拆，不是一句口号

每个项目都从根节点开始，拆成子项目 / 目标，再拆成成果与任务。

项目（root）
├── 子项目 / 分支（branch）
│   ├── 目标（goal）
│   │   ├── 成果（outcome）
│   │   │   └── 任务（task）
│   │   └── 成果（outcome）
│   └── 目标（goal）
└── ...

这棵树的价值不在于“好看”，而在于每一个任务都能回溯到它服务的成果，每一个成果都能回溯到项目目标。

2. 任务有成本，成本有口径

任务支持两种回报口径：

  • 给票：以票权额结算；
  • 现金：以人民币金额结算。

项目树同时汇总计票支出、计票收入、现金支出、现金收入与计划成本。 这让“钱花在哪、换回了什么”不再是一笔糊涂账。

3. 财务可核查

项目详情可以进入透明财务、投入明细、收入明细、票据份额与流水。 关键不是“有报表”，而是报表能对上：

  • 投入与票据的对应关系；
  • 任务成本与成果的对应关系；
  • 分红 / 结算与持票人的对应关系。

4. 份额可流转，但不是证券

原型提供票据转让能力，但是否可转让、如何定价、如何合规，必须由项目规则与当地法律共同约束。 技术上的可转让，不等于法律上的可发行。

5. 公共性有位置

项目类型分为：

类型含义
全公益项目全部收益用于公益目的
轻公益项目运营满 10 年后须退还投入并捐献给政府
私有项目不进路演池，仅创建者与持票人可见

公共性不是成功之后的“可选项”，而是在项目创建时就要选择的类型。

三、一个样板项目的完整读法

以“青禾智慧农场”为例：

  1. 先看根节点：项目解决什么问题？为什么是冷链，而不是别的？
  2. 再看目标：冷链共建、社区团购闭环，分别对应什么可验证的结果？
  3. 再看成果：县域冷链仓、线路开通、溯源看板，是否真的支撑目标？
  4. 再看任务：仓租、制冷设备、冷藏车、IoT 探针，每一项的成本与负责人是谁？
  5. 最后看账：投入、收入、票权、分红是否对得上？

如果这五步有任何一步说不清，项目就还不适合被复制。

四、从样板到复制：六个检查

  • 项目是否有明确的本地运营主体与合规路径？
  • 目标是否可以拆成可验收的成果与任务？
  • 每一项任务是否有成本口径、负责人和完成标准？
  • 收入与分红是否有可核查的账本，而不是只有汇总数字？
  • 项目类型（全公益 / 轻公益 / 私有）是否在创建时说明？
  • 如果失败，退出、清算与责任如何安排？
明星项目不是“看起来最赚钱的项目”，
而是“最经得起被拆开看”的项目。 SHOWCASE CRITERIA
