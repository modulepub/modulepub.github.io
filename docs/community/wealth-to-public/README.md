<p class="doc-lead">

## 一、先厘清两个节点

很多人把“创业成功”与“公益达成”混为一谈。它们是两个不同的阶段。

| 维度 | 创业成功 | 公益达成 |
| --- | --- | --- |
| 触发 | 股本池至少 2 亿 USDT，投票通过 | 项目产出能覆盖自身运转，社区讨论后宣布 |
| 合约 | 当前合约执行回赠与担保清退 | 当前合约不自动切换 |
| 分配 | 股本池按持有 GCC 比例赠送 | 方向为 KYC 账户均权投票、均分 |
| 治理 | 仍是合格质押地址一人一票 | 1 个 KYC 账户 = 1 票 |
| 公共性 | 为公共阶段准备资金与治理基础 | 公共品成为主要去向 |

**创业成功是“资本侧的一次结算”，公益达成是“治理侧的一次转换”。**

## 二、创业成功：股本池回到持有人

### 2.1 条件

1. 股本池至少 **200,000,000 USDT**；
2. 投票持续 7 天；
3. 截至时股本池仍然丰盈；
4. 外部仍有 GCC；
5. 赞成多于反对；
6. 不能与破产投票或终止代理同时进行。

### 2.2 执行

```text
赠送总额 = 结算时股本池全部 USDT
某人可领取 = 赠送总额 × 本人持有 GCC ÷ 当时外部 GCC 总量

持有口径（结算时冻结）：
- 钱包中的 GCC
- 本人质押的 GCC
- 本人卖单锁定的 GCC
- 库存不算任何人的持有
```

同时：

- 清退全部担保公司；
- 把当时的担保价退回担保人；
- 股本池从 0 重新累计；
- 持有人之后各自领取赠送；
- 再转走 GCC，不改变已冻结的赠送份额。

### 2.3 一个只用于说明的算例

假设结算时：

- 股本池：200,000,000 USDT；
- 外部 GCC：100,000,000 枚；
- 你持有：1,000 枚。

则你的赠送份额为：

```text
200,000,000 × 1,000 ÷ 100,000,000 = 2,000 USDT
```

如果外部 GCC 是 200,000,000 枚，则每枚对应 1 USDT。
**这只是公式演示，不是收益预测，也不代表创业成功一定会发生。**

### 2.4 为什么不是“项目方回购”

回购通常是项目方用现金从市场买回代币，价格由双方或市场决定。
这里的动作是：

- 合约把股本池中的 USDT 按持有比例分配给持有人；
- 担保人退出，担保价退回；
- 不涉及股权、证券或交易所上市。

它更像“社区把共同积累的股本，按持有份额还给参与者”，而不是一次市场交易。

## 三、创业成功之后：代理公司继续运转

创业成功不等于项目停止。代理公司还要继续运营，只是规则发生变化。

### 3.1 红利的第一顺序

代理公司的红利，先用于：

1. 公司运转；
2. 已经承诺的设施福利。

这两项由代理公司在账上安排，合约不代为支付。安排之后仍有富余，才进入积分体系。

### 3.2 积分：1 积分 = 1 克黄金

- 富余红利由代理公司按金价记为积分；
- 1 积分锚定 1 克黄金；
- 记账时查询金价大盘，查不到就沿用上一次价格；
- 部署时初始金价为每克 80 USDT；
- 积分可以转账；
- 代理公司也可以把积分池中的积分转给地址。

### 3.3 会员消费与积分归属

财务上传账本时，会标明这笔红利是否来自会员消费：

- 来自会员消费，且该账户当时持有 GCC（钱包 / 质押 / 卖单锁定，至少 1 枚）→ 积分转给该账户；
- 否则 → 积分进入积分池。

这让“消费”与“持有”产生连接，但积分不是股权，也不是对 GCC 价格的承诺。

## 四、公益达成：治理权的转换

### 4.1 什么叫“达成”

当项目产出能够覆盖自身运转，不必再靠持续注入分红或股本池来维持，社区可以讨论进入公益阶段。

这不是一个自动触发的合约状态，而是需要事实、治理与公开讨论的判断。

### 4.2 治理怎么变

| 创业期 | 公益阶段（方向） |
| --- | --- |
| 合格质押地址一人一票 | 1 个 KYC 账户 = 1 票 |
| 分红按质押数量 × 时间 | 红利是否发、发多少由均权投票决定 |
| 分配按票权加权 | 方向为合资格持有人均分 |
| 代理公司主导运营 | 社区共治 + 代理执行 |
| 股本池 / 担保池为核心 | 自持产能与公共品为核心 |

KYC 认证暂由担保机构承担，认证与链上地址映射数据公开可查。
“一人一票”要解决的是女巫攻击与身份重复，而不是把治理变成无门槛的刷票。

### 4.3 公共品的六个方向

白皮书给出的方向包括：

- 免费医疗；
- 免费住养；
- 荣誉激励；
- 科研投入；
- 危机应对；
- 扩大产能。

这些不是“今天已经实现的福利”，而是公益阶段资金的可能去向。
具体做什么、做多少，应由均权治理决定，并受当地法律与运营能力约束。

## 五、为什么要把“转公益”写进规则

### 5.1 防止“永远的下一次”

如果公共性只是口头承诺，它很容易被无限期推迟。
把它写进阶段转换，至少让社区有一个必须讨论的节点。

### 5.2 防止“成功后失控”

创业成功后，资本方的目标可能从“共建”转向“套现”。
提前设计股本回赠、担保清退与治理转换，可以降低这种漂移。

### 5.3 让公共性成为“默认选项”

当公共阶段有明确的治理规则与资金方向，公益就不再依赖某个人的善意，而是成为系统的一个可选状态。

## 六、这条路上仍有很多难题

| 难题 | 说明 |
| --- | --- |
| KYC 与隐私 | 如何验证“一人一账户”，又不把身份数据暴露在链上？ |
| 女巫攻击 | 一个人控制多个账户，均权投票是否会被操纵？ |
| 治理冷漠 | 均权不等于人人参与，投票率低时如何避免少数人控制？ |
| 福利可持续 | 免费医疗、住养需要长期现金流，不能只靠一次性资金 |
| 法律与税务 | 不同司法辖区对分红、积分、公益支出有不同要求 |
| 代理激励 | 公益阶段代理公司如何保持运营动力？ |

承认这些问题，不会削弱愿景；相反，它让愿景更接近可执行的制度。

## 七、一张阶段图

```text
创业期
  资本进入 → 项目运营 → 利润回流 → 质押分红
        │
        ▼
创业成功（条件触发 + 投票）
  股本池回赠 → 担保清退 → 代理继续运营 → 积分体系
        │
        ▼
公益达成（事实 + 治理判断）
  KYC 一人一票 → 红利均分方向 → 医疗 / 住养 / 科研 / 危机应对
```
