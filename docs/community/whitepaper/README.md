## 一、问题：资本进入社区之后，通常会发生什么？

大多数“资本 + 社区”的故事，卡在三个断点上。

### 1.1 信任断点：钱从哪里来，去了哪里？

社区项目往往缺少可核查的账本：

- 投入靠转账截图；
- 支出靠人情说明；
- 收益靠口头承诺；
- 退出靠“以后再说”。

一旦规模变大，信任就只能依赖中心化主体。主体一变，规则就断。

### 1.2 分配断点：谁创造了价值，谁拿走了价值？

传统结构里，资本优先获得回报，劳动获得工资，社区承担外部性。项目成功之后，创造价值的人往往已经离场，留下的是股权与估值。

### 1.3 退出断点：赚钱之后，公共性去哪里？

“先赚钱，再捐钱”是常见的叙事，但它把公共性放在了最后一环。只要中间任何一步改变方向，公益就可能变成公关。

GCC 的设计，试图把这三个断点提前写进规则：

- **信任**：用链上账本与公开报表替代口头承诺；
- **分配**：用质押数量 × 时间计算分红票权；
- **公共性**：在合约里预置“创业成功 → 股本回赠 → 公益阶段”的路径。

## 二、五条设计原则

| 原则 | 含义 | 对应机制 |
| --- | --- | --- |
| 固定供应 | 不增发，不用通胀稀释后来者 | GCC 总量锁死 2 亿枚 |
| 透明账本 | 资金、质押、分红、投票可核查 | 链上状态 + 公开档案 |
| 贡献定价 | 分红与质押数量、时长相关 | 票权 = 数量 × 有效秒数 × 系数 |
| 风险共担 | 担保人锁入 USDT，破产时并入股本池 | 担保池 + 破产清算 |
| 公共性预置 | 成功之后不是“可捐可不捐” | 创业成功回赠 + 公益阶段 |

## 三、五个角色

| 角色 | 做什么 | 不做什么 |
| --- | --- | --- |
| **持有人** | 用 USDT 兑入 GCC；质押；领取分红；参与投票 | 不把 GCC 当作存款或固定收益产品 |
| **代理公司** | 在当地运营社区项目；注入利润；申请股本借用 | 不是发行人，不向公众出售证券式份额 |
| **担保公司** | 锁入担保价；承担保本与制衡；暂任 KYC 认证 | 不用担保份额改写链上“一人一票” |
| **社区项目** | 接受审核，使用借入资本，产生真实回馈 | 不把超出允许截留的部分留在账外 |
| **社区** | 形成共识、投票、监督、决定公共品方向 | 不依赖单一股东或单一国家主体 |

::: info 一个关键区分
**分红票权** ≠ **治理投票权**。
前者按质押数量 × 时长加权，用于分钱；后者在当前链上按“合格质押地址一人一票”，用于破产、创业成功、终止代理与股本借用。公益阶段的“一人一票”按 KYC 账户均分，是另一个阶段的方向。
:::

## 四、GCC 是什么

GCC（General Consensus Coin，通用共识币）是运行在 TRON 上的 TRC20 项目币。

- 总量 **200,000,000 枚**，部署后固定，不再增发；
- 初始机制定价 **1 USDT / 枚**，机制定价只升不降；
- 只能通过向兑换合约支付 USDT 从库存兑入；
- 不提供持有人之间的私价买卖，也不提供二级市场；
- 公价卖单、公价买单由合约按队列处理；
- 挂单、质押中的 GCC 不进入钱包流通，也不能直接转账。

“机制定价只升不降”描述的是合约内的定价函数，不等于市场价格，也不等于持有人一定能够以更高价格退出。流动性、项目运营与监管环境都可能影响实际结果。

## 五、资金如何循环

```text
持有人用 USDT 兑入 GCC
        │
        ▼
   USDT 进入股本池
        │
        ▼
代理公司申请股本借用 ──► 合格质押地址投票 ──► 资金进入社区项目
        │
        ▼
项目产生利润（链外截留运营成本与约定比例）
        │
        ▼
净额注入合约
   ├─ 1/3 补入股本池
   └─ 2/3 按质押票权分配
        │
        ▼
持有人领取 USDT 分红 / 本土货币分红
```

### 5.1 兑入与兑出

- 兑入：支付 `数量 × 机制定价` 的 USDT，从库存取得 GCC；
- 兑出：股本池余额足够时，按机制定价支付 USDT，GCC 回到库存；
- 股本池不足时，不强行支付，自动生成公价卖单排队；
- 卖单可以撤销，破产结算进行中除外。

### 5.2 公价，不设私价

合约只提供公价卖单与公价买单：

- 卖单不填价格，挂出时绑定当时机制定价；
- 买单不填价格，按当时机制定价锁定 USDT；
- 都由股本池或库存按队列成交，可以拆开；
- 不撮合持有人之间的私下交易。

这不是“去中心化交易所”，而是一个由合约规则约束的兑付与退出通道。

## 六、分红：数量 × 时间

### 6.1 公式

```text
某地址票权 = Σ（每笔质押数量 × 该笔与分红期重叠的有效秒数 × 时间系数）

时间系数：
- 普通质押：1
- 该笔仓位上持续锁有大于 0 的担保价的重叠秒数：2
```

分红来源：

| 来源 | 分配方式 |
| --- | --- |
| 社区利润注入 | 1/3 进股本池，其余按质押票权 |
| 任何人捐入 | 100% 按质押票权 |
| 无人在分红区间内 | 进入股本池，不结转给下一次 |

分红先记入持有人“可领取”，由本人领取；不在入账时直接打到各地址。

### 6.2 一个只用于说明的算例

假设某次质押人分红总额为 700,000 USDT：

- 甲：100,000 枚，连续质押 10 天；
- 乙：500,000 枚，连续质押 2 天。

按“数量 × 秒数”计算，两人的权重刚好相等，因此各得 350,000 USDT。
这个例子只说明公式，不代表真实收益，也不构成任何承诺。

### 6.3 本土货币分红

链上不收本土货币。代理公司在当地按质押票权支付，持有人在自己的账户中确认到账。
确认没有期限，未确认也不会被自动放弃；合约不记录这笔确认。

## 七、治理：谁能决定什么

当前链上特别投票有四类：

| 类型 | 发起条件 | 计票 |
| --- | --- | --- |
| 破产清算 | 有公价卖单挂满 1 年仍未兑完 | 合格质押地址一人一票 |
| 创业成功 | 股本池至少 2 亿 USDT | 合格质押地址一人一票 |
| 终止代理 | 创业成功之后 | 合格质押地址一人一票 |
| 股本借用 | 代理公司申请 | 合格质押地址一人一票 |

合格质押的条件：

- 可解除时间晚于投票截止；
- 这样的在押合计至少 1 GCC；
- 1 枚与更多枚都只有一票；
- 不看钱包余额，不按担保份额加权。

产品页面上的投票另要求实名；合约本身不读取 KYC，也不阻止绕过页面的直接调用。

### 7.1 七天与冷却

- 每类特别投票持续 7 天；
- 同一类型同时只能有一场；
- 结束后锁定 7 天，才能再次发起同类型；
- 破产与创业成功不能同时进行；
- 终止代理不能与上述两类同时进行。

## 八、创业成功：股本池回到持有人

创业成功的条件：

1. 股本池至少 **2 亿 USDT**；
2. 投票 7 天，赞成多于反对；
3. 结算时股本池仍然丰盈；
4. 外部仍有 GCC。

执行时：

- 把当时股本池中的全部 USDT，按每人持有的 GCC 比例赠送；
- 持有量按结算时冻结：钱包 GCC、本人质押、本人卖单锁定的 GCC；库存不算；
- 清退全部担保公司，退回担保价；
- 持有人之后各自领取赠送；
- 再转走 GCC，不改变已冻结的赠送份额。

这不是“项目方回购”，也不是“保证上市”。它是合约在特定条件满足后执行的一次性分配。

## 九、公益达成之后

“公益达成”是远景，不是当前合约自动切换的状态。

当项目产出能够覆盖自身运转，不再依赖持续注入分红或股本池来“续命”，社区可以讨论进入公益阶段。方向包括：

- 投票权按 **1 个 KYC 账户 = 1 票**；
- 红利是否发、发多少、发给谁，由均权投票决定；
- 分配方向从“按质押加权”转向“合资格持有人均分”；
- 公共品方向：免费医疗、免费住养、荣誉激励、科研投入、危机应对、扩大产能。

::: warning 当前合约不实现公益阶段
本期链上合约只实现创业期规则。公益达成与均分制属于链下治理与远期规则，白皮书先写方向，不纳入当前合约的自动逻辑。
:::

## 十、它不能解决什么

一份诚实的白皮书，必须说明边界。

- **不能保证收益**：机制定价只升不降，不等于投资回报；
- **不能消除智能合约风险**：代码漏洞、私钥泄露、预言机错误都可能发生；
- **不能替代法律合规**：代币、募资、分红、税务在不同司法辖区有不同要求；
- **不能自动实现公益**：公益阶段需要治理、运营与监督，合约只提供一部分基础设施；
- **不能保证流动性**：股本池不足时，兑出会排队；
- **不能消除人的因素**：代理公司、担保公司、KYC 机构仍由人组成，仍需被监督。
