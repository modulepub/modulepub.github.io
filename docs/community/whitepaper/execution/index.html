执行与边界

约 1821 字大约 6 分钟

EXECUTION · RULES BEFORE NARRATIVE

白皮书负责解释“为什么”，这一页负责说明“到底怎么执行、哪里会失败、什么不在合约里”。 它更像一份技术附件：不写愿景，只写边界。

交互前先核实

合约地址、部署网络、审计状态与前端入口，请以仓库中的 deployments 文件、官方公告和链上浏览器为准。 不要在未核实的地址上授权、转账或质押。

一、本期链上已定的关键规则

  1. 创始人部署时即在任代理与在位担保；代理地址一旦写入不可更换；合约没有暂停开关。
  2. 社区利润注入时，金额的 1/3 进入股本池，其余按质押票权分配。
  3. 任何人捐入的分红，100% 按质押票权分配；没有单独切给担保人的 30%。
  4. 票权 = 数量 × 该仓位与账单重叠的秒数；担保价大于 0 的重叠秒数，系数为 2。
  5. 账单区间内只有一个地址有票权，该地址拿走全部；一个地址都没有，进入股本池。
  6. 分红记入可领取，由本人领取；不在入账时直接转账。
  7. 最小质押 1 GCC；普通质押人自写可解除时间；担保人的质押要等破产清算或创业成功之后才能解除。
  8. 破产、创业成功、终止代理、股本借用：合格质押地址 一人一票。
  9. 新担保人须有一笔连续满 1 年且仍在押的质押，再锁入大于 0 的担保价。
  10. 破产的唯一发起条件：有公价卖单挂满 1 年仍未兑完；投票 7 天。
  11. 创业成功的条件：股本池至少 2 亿 USDT；投票 7 天；赞成多于反对；外部仍有 GCC。
  12. 创业成功执行时，把股本池全部 USDT 按持有量赠送，并清退全部担保、退回担保价。
  13. 公价卖单和买单都由股本池或库存按队列处理，可以拆开成交；不提供私价买卖与二级市场。
  14. 本土货币不进合约，由代理在当地按票权支付，持有人自行确认到账。
  15. 创业成功后的富余红利可按金价记为积分，1 积分锚定 1 克黄金；积分可转账。
  16. 终止代理只能在创业成功之后发起；通过后代理地址清空，合约不改写新地址，也不划转资产。

二、角色与接口

2.1 持有人

接口作用主要失败条件
deposit(amount)支付 USDT，从库存取得 GCC库存不足、USDT 未到账、数量为 0
redeem(amount)进入公价卖单队尾，按队列兑付GCC 未到账、数量为 0
placePublicSell(amount)从钱包挂公价卖单GCC 未到账、数量为 0
placePublicBuy(amount)按机制定价锁定 USDT，从库存成交USDT 未到账、数量为 0
cancelOrder(orderId)撤卖单，剩余 GCC 回钱包非本人、非排队中、已破产
cancelBuy(orderId)撤买单，退回剩余 USDT非本人、非排队中
stake(amount, unlockTime)从钱包质押，单笔至少 1 GCC低于 1 GCC、超过额度、时间不合法
unstake(positionId)到期解除质押非本人、未到期、会破坏未结束投票资格
claim()领取 USDT 分红可领取为 0
donateUsdtDividend(...)任何人捐入分红数量为 0、区间无效
claimVentureGift()领取创业成功赠送未成功、已领过、持有为 0

2.2 代理公司

接口作用
contribute(amount, periodStart, periodEnd)注入净额；1/3 进股本池，其余按票权
requestEquityWithdraw(amount)申请股本借用，投票 7 天
GccProjectCatalog.publish(...)发布社区项目目录
postProfit(...)创业成功后按金价记积分
syncGoldPrice()查询金价，查不到沿用上一次
transferPoolPoints(...)把积分池中的积分转给地址

setProxy(next) 会失败。代理地址不可更换。

2.3 担保公司

接口作用
bidGuarantee(amount)锁入或追加担保价
releaseGuarantor()破产后尝试兑完所有卖单，再解除身份
voteEquityWithdraw(requestId, yes)对股本借用投票
executeEquityWithdraw(requestId)截止后按结果执行

担保份额只用于链下商量，不改变链上借用的一人一票，也不用于链上分红。

三、链上状态

状态含义
inventory合约内尚未放出的库存
orderTotal全部未成交卖单的 GCC 合计
buyLocked未成交买单锁定的 USDT
totalStaked质押量合计
equityPool股本池 USDT
quote机制定价，初始 1 USDT，只升不降
claimableUsdt各地址可领取的 USDT 分红
guarantors / guaranteePrices在位担保人与担保价
ventureDone是否已执行创业成功
bankrupt是否已执行破产清算
proxy在任代理地址

恒等式：

总供应 = 库存 + 流通量 + 卖单量 + 质押量 = 200,000,000
对外债权 = 流通量 + 卖单量 + 质押量 = 总供应 − 库存
合约托管 USDT = 股本池 + 分红池 + 担保池锁定

四、失败与边界

4.1 兑出失败不是“系统故障”

当股本池不足以支付整笔兑出时，合约不会从池中扣成负数，而是把该笔 GCC 自动挂成公价卖单排队。 这是设计行为，不是异常。

4.2 破产不是“项目方申请”

破产只能由“公价卖单挂满 1 年仍未兑完”触发，并由合格质押地址投票。 投票期间如果卖单已被兑完，本轮终止，不清算。

4.3 创业成功不是“上市”

它不涉及股权、证券或交易所上市，只是合约在股本池达到条件后，把池中 USDT 按持有量回赠并清退担保。 不要把它理解为投资回报承诺。

4.4 合约不做的事

本期合约明确不做：

  • 私价买卖、二级市场；
  • 自定义人类决议、项目备案投票；
  • 更换代理地址；
  • 按担保份额否决链上借用；
  • 用本土货币进合约；
  • 自动执行公益阶段；
  • 保存决议正文与 KYC 正文。

代码不是法律

合约能执行资金与计票，但不能替代公司登记、税务、消费者保护、反洗钱与证券监管。 任何真实运营都必须在当地法律框架内进行。

五、安全与审计

在参与之前，至少确认：

  • 合约地址来自官方渠道，并与 deployments 文件一致；
  • 确认当前网络（主网 / 测试网）与前端提示一致；
  • 查看合约是否经过独立审计，审计范围是否覆盖兑换、质押、分红、投票；
  • 确认代理地址、担保地址与 KYC 机构的公开信息；
  • 小额测试兑入、质押、领取、撤单全流程；
  • 不要向任何“客服”提供私钥、助记词或短信验证码。

六、一页总结

规则先于规模，账本先于叙事，
退出机制先于增长故事。 EXECUTION BEFORE PROMISE
