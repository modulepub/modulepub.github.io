THE COMMON BASE

两种表达，同一套底层信念

01

契约先于自由

边界写进代码，接口成为团队与 AI 的共同语言。自由生长，但不失控。

02

账本先于叙事

每一笔投入、每一份收益都可追溯。先让事实可核查，再让故事被相信。

03

人先于资本

资本是工具，不是目的。技术效率最终要回到人的尊严与公共生活。
