# tg-manage-vue

TG-boot 倉庫內的 **後台管理端** 示例工程：基於 Vue 3、TypeScript、Element Plus、Vue Router、Pinia、Axios、i18n、Vite 等，與後端 starter 配套演示。

## 本地運行

```bash
cd tg-manage-vue
npm install
npm run dev
```

打包發佈：

```bash
npm run build
```

**源碼路徑**：`tg-boot/tg-manage-vue/`
