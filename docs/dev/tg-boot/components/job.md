# spring-boot-starter-job（已从仓库移除）

> 当前 `spring-boot-starter-module` 聚合中**不再包含**独立的 `spring-boot-starter-job` 模块。若项目仍需 XXL-Job 等定时任务能力，请在业务 runner 中自行引入对应依赖并配置，或参考历史版本仓库。

定时任务集成说明曾位于本页；新部署请以 `tg-boot` 仓库 `pom.xml` 与实际模块列表为准。
