SIX SUPPORTSWhy it holds together

Starter-based capabilities

Add a dependency to assemble; remove it to unload. Business modules do not rebuild infrastructure.

Contracts as boundaries

Cross-module calls only use *-api contracts, DTOs and enums, never another module’s implementation.

AUTO routing

Local provider first, MQ only when needed. The business code stays the same.

Architecture gates

Forbidden dependencies become tests, enforced by CI rather than memory.

One-command environment

JDK, Maven, MariaDB, Redis and Node live under .tools and are prepared by one script.

Split without rewrite

Start as one process. Split by domain later; what changes is deployment, not the business code.
