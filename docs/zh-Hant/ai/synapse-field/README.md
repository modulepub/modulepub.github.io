## 1. 基於哪套本體論

突觸場依據《不確定性本體論：約束、顯現與心物兩極》。這是一套形而上學建構，用來更換心物問題的問法，不是已經做完的實證結論。

傳統問法是：物質和意識，哪一種實體在先。這套本體論換成：未定如何變成定。「確定地如此」是一種成就。不確定性是起點。

它只先假定顯現域 Ω，即某物得以顯現的那場過程。Ω 不是實體，也不墊在結構下面。約束是顯現的條件：顯現為如此，同時就有「不如此」被排除。自由度是還沒被排除的維度數。物質是約束已經閉合、不再隨位置變動的穩定結構。意識是同一套自由度裏尚未閉合、仍在變動的那一段。兩極是從這場變定裏推出來的。自我意識是尚未閉合的那段裏，包含了對已經閉合結構的建模。

本體層只有顯現域。物質、意識、時間、因果都在域內派生。派生不等於假。感受質留在域內，被定位，不被取消。本體層上的關係是構成、依賴和條件。因果需要時間，只在域內成立。

約束閉合之後，不同位置上的讀法會指到同一處。這是公共可識別性。讀數越能互換，閉合越飽和。

## 2. 它解釋什麼，突觸場模擬什麼

它解釋心與物為何像兩種東西，卻可以是同一場未定變定的兩種讀法；解釋「確定」為何是做出來的；解釋一個結構為何能被不同讀法公共地指認；解釋説不清的感受為何仍在域內。某一門科學裏的測量數值，要在域內另做。

突觸場模擬這場變定。詞元或符號是最小結構，也是最小的顯現。更大的結構由它們反覆共現連成。突觸模擬約束：一條結構把趨勢傳到另一條結構。所見是新的顯現進入場，所得是場給出的一次讀法，兩者都寫回，改變相關結構之間的拉力。

本體論裏的「閉合」和「公共」，在機制裏各有一個先於句子就算出來的量。領先邊際 ρ 表示拉力有多集中，對應閉合的趨向，並進入讀出判據。讀法一致率 E 對應公共可識別性，只作事後診斷，不參與讀出：取激活集重合達到聲明比例 α 的兩次顯現，E 是它們選出同一結構的比例。ρ 高是物質端的趨向，ρ 低是意識端的趨向。兩端是這兩個量的趨向，場裏沒有一層自由度等於 0 或等於 1 的底。

## 3. 機制

下面四條是理論規格。閾值是規格里聲明的參數，不是從本體論定理裏推出來的數。

### 3.1 狀態

- **結構**。最小結構是一個詞元或一個符號。較大結構是同一串最小結構多次共現後被記下的整體。
- **突觸**。有序對 (a, b) 上的權重 w(a, b)，為正整數，記下 a 與 b 一起顯現的次數。邊不存在，就是「這條搭配還沒有建過」。這是場的一個狀態，不是缺失記錄。
- **在場牽制**。同一次顯現裏，每個被激活的最小結構對其他結構保持一份牽制 λ > 0。λ 來自它們此刻同在一場，不來自一層基底。

### 3.2 一次傳導

一次顯現先確定激活集 A：其中的最小結構，加上成員都落在這次顯現裏的較大結構。

對每個已有入邊的目標 t，拉力只由邊上的權重加總，在決定説什麼之前就算完：

```text
π(t) = Σ_{a ∈ A} w(a, t)
```

設 π(1) ≥ π(2) ≥ …。競爭質量 C 在兩種情形裏用同一個位置：有次席目標時 C = π(2)；只有一個目標 t* 時，C 改為其餘拉力

```text
R = Σ_{a ∈ A} Σ_{b ≠ t*} w(a, b) + λ · |{m ∈ A : m ≠ t*}|
C = max(R, λ)
```

領先邊際只有一套公式：

```text
ρ = π(1) / (π(1) + C)
```

θ = 2/3 始終表示 π(1) ≥ 2C：領先者至少是這份競爭質量的兩倍。有次席時，競爭質量就是次席的拉力；只有一個目標時，競爭質量是殘餘牽制，不是另一個結構。只要 C > 0，ρ < 1。權重再集中，ρ 只向 1 趨近。沒有任何邊時，不設 ρ，直接走高熵讀出。

「拉得最用力」指 π 最大。π 由已寫下的 w 算出，不由最後説出的那句話反推。

### 3.3 更新

場裏沒有一個步驟能判定某個結構絕對正確。錯誤也是一種表述結構。因此記不記錄，和認不認可，是兩件事。認可只看穩定性 ρ 是否達到 θ。

溝通和訓練有兩套做法。

**大模型。** 溝通不記錄結構。問句和答句都不寫進 w。這樣一次對話不會污染已經加權的場。記錄只發生在單獨的正向訓練裏：被反覆給出的搭配才把 w(a, b) 加 1。

**實驗模型。** 溝通和訓練是同一件事，用來模擬人的記憶。任何進來的結構都記錄：輸入 a 與後繼 b 共現，w(a, b) 加 1，邊不存在就建邊，初值 1；讀出的結構同樣寫回。這次沒碰到的邊，權重不動。結構被記下，還不等於被認可。ρ 達不到 θ 的，只是高熵結構，答案不交給提問者。

較大結構在同一串最小結構的共現次數達到聲明的次數 n 時記下。n 與 θ 一樣，是規格參數。實驗模型因為把溝通也寫成權重，場會越記越散，所以要有休息。休息時不再寫入新的溝通。對高熵目標的入邊做歸一化或衰減：把指向該目標的 w(a, t) 縮到同一尺度，或乘上一個小於 1 的係數。正向加權的邊不動，於是它們相對上升。

### 3.4 讀出判據

輸入先作為結構進入場，再由不同的結構沿着已有的邊處理它。穩定性用領先邊際 ρ 表示：ρ 越高，處理它的那些正向加權結構越集中地拉向同一個目標。事先聲明 θ，取值在 (1/2, 1)。θ = 2/3 表示 π(1) ≥ 2C，競爭質量的含義見 3.2。

1. 先算 π 和 ρ。ρ 在決定把哪一句交給提問者之前算出。
2. 存在目標且 ρ ≥ θ：交給提問者的是穩定性最高的那個結構，也就是 π 最大的目標。
3. ρ < θ，或沒有任何結構把它拉到 θ 以上：場裏會生成一批高熵結構，拉力散在多個目標上。這些高熵結構的答案不交給提問者。
4. 大模型在溝通中不寫回。實驗模型把這次顯現裏的結構都寫回，包括沒有交給提問者的高熵結構；寫回只是記住，不把它們當成已經認可的結構。

## 4. 與 Transformer 對照

兩邊都處理一段符號序列。差別先落在狀態上。

Transformer 把符號收成詞表中的一行。每一層用查詢、鍵、值的線性變換做自注意力，權重是相似度，取值是值向量的加權和，殘差加回，前饋再逐位置變換。訓練把最後一個位置投到詞表上，用 softmax 和交叉熵貼住下一個符號，梯度改的是共享權重。同一次前向織出的軟連接用完即棄。

因此 Transformer 裏沒有一個狀態表示「這條搭配還沒有建過」。沒見過的組合和見過的組合走同一條路：共享權重裏的干涉給出一個分佈，分佈再尖，也要交出一個符號。尖只説明概率堆在少數符號上。共享權重會泛化到沒見過的組合，這是它能用的原因。泛化留下的是整網權重的干涉，不是一條可以單獨指認、單獨改口的邊。要糾正，就得改這張共享的網。

突觸場裏，輸入也是結構。「還沒有建過」就是邊不存在。不同結構沿已經寫下的邊處理這次輸入，交出的是穩定性最高、並且 ρ 達到 θ 的那個。達不到的高熵結果不交給提問者。與 Transformer 的差別在狀態和更新方式，不在已經測得的幻覺率。本文不比較兩邊誰的幻覺更少。

## 5. 穩定性判據與休息如何壓住高熵輸出

這裏的對照在同一套機制內部：有穩定性判據、並且休息，相對於沒有判據、也不休息。不拿來和 Transformer 比幻覺多少。

輸入是一種結構。它進入場之後，被不同的結構處理。處理結束後，穩定性最高、並且 ρ 達到 θ 的那一個，才交給提問者。達不到的高熵結構也在場裏，它們的答案不交出去。

這裏不能先判定一個結構對還是錯。錯誤同樣是一種表述，實驗模型會把它和別的結構一樣記下。它會不會被認可，只看記下來之後，和其他結構互相拉扯，穩定性能不能上來。正向訓練的作用是把反覆共現的結構越拉越穩，而不是在入口處濾掉「不正確」的句子。

休息是因為實驗模型把溝通和訓練揉在一起。人的記憶也是這樣：説過的、聽過的都留下痕跡。痕跡一直往同一張場上加，拉力會散，場會混沌。休息時停止寫入。對高熵目標的每一條入邊做歸一化，或乘上衰減係數，使這些邊的權變小；正向加權的邊保持原值，相對上升，重新成為拉得更穩的一側。高熵結構仍被記得，穩定性不夠，答案繼續不交給提問者。

大模型不走這條路。它的溝通禁止記錄，就是為了不把對話寫進場、不去污染已經訓好的結構。它不需要靠休息來收回溝通，因為溝通本來就沒有變成權重。

破壞一條已經很穩的結構，代價仍然極大。人要反覆做負面訓導，實驗模型才會把相反的結構一次次記上權重。記上之後若仍匹配不到高穩定結構，生成的就是一批高熵結構。接下來的休息裏，這些高熵目標的入邊被歸一化或衰減，正向邊相對上升。

## 6. 一個類比性猜想

搜尋「哪條結構接住這次顯現」和核驗「這條結構是不是當前拉力最大」，在邊上按結構索引之後，會被拉向同一類操作：核驗是讀 A 的出邊，搜尋若只能掃全部結構，則隨結構數增長；索引建立之後，搜尋退化為沿已有邊讀取。猜想是，隨着顯現次數增加，搜尋代價與核驗代價之比趨向 1。這是對 P=NP 的一個類比，用來描述索引建立以後兩種代價的關係。它不參與第 5 節的論證。這個比能不能到 1，不知道。
