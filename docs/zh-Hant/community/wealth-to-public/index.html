共創財富後轉公益

约 1987 字大约 7 分钟

FROM WEALTH TO PUBLIC GOOD · THE SECOND CURVE

大多數項目只設計“如何成功”，很少設計“成功之後怎麼辦”。 GCC 的特別之處，是把“成功之後”提前寫進規則：先讓共創者拿回股本，再讓代理公司繼續運轉，最後把治理權交給均權的 KYC 賬户。

一、先釐清兩個節點

很多人把“創業成功”與“公益達成”混為一談。它們是兩個不同的階段。

維度創業成功公益達成
觸發股本池至少 2 億 USDT，投票通過項目產出能覆蓋自身運轉，社區討論後宣佈
合約當前合約執行回贈與擔保清退當前合約不自動切換
分配股本池按持有 GCC 比例贈送方向為 KYC 賬户均權投票、均分
治理仍是合格質押地址一人一票1 個 KYC 賬户 = 1 票
公共性為公共階段準備資金與治理基礎公共品成為主要去向

創業成功是“資本側的一次結算”，公益達成是“治理側的一次轉換”。

二、創業成功：股本池回到持有人

2.1 條件

  1. 股本池至少 200,000,000 USDT；
  2. 投票持續 7 天；
  3. 截至時股本池仍然豐盈；
  4. 外部仍有 GCC；
  5. 贊成多於反對；
  6. 不能與破產投票或終止代理同時進行。

2.2 執行

贈送總額 = 結算時股本池全部 USDT
某人可領取 = 贈送總額 × 本人持有 GCC ÷ 當時外部 GCC 總量

持有口徑（結算時凍結）：
- 錢包中的 GCC
- 本人質押的 GCC
- 本人賣單鎖定的 GCC
- 庫存不算任何人的持有

同時：

  • 清退全部擔保公司；
  • 把當時的擔保價退回擔保人；
  • 股本池從 0 重新累計；
  • 持有人之後各自領取贈送；
  • 再轉走 GCC，不改變已凍結的贈送份額。

2.3 一個只用於説明的算例

假設結算時：

  • 股本池：200,000,000 USDT；
  • 外部 GCC：100,000,000 枚；
  • 你持有：1,000 枚。

則你的贈送份額為：

200,000,000 × 1,000 ÷ 100,000,000 = 2,000 USDT

如果外部 GCC 是 200,000,000 枚，則每枚對應 1 USDT。 這只是公式演示，不是收益預測，也不代表創業成功一定會發生。

2.4 為什麼不是“項目方回購”

回購通常是項目方用現金從市場買回代幣，價格由雙方或市場決定。 這裏的動作是：

  • 合約把股本池中的 USDT 按持有比例分配給持有人；
  • 擔保人退出，擔保價退回；
  • 不涉及股權、證券或交易所上市。

它更像“社區把共同積累的股本，按持有份額還給參與者”，而不是一次市場交易。

三、創業成功之後：代理公司繼續運轉

創業成功不等於項目停止。代理公司還要繼續運營，只是規則發生變化。

3.1 紅利的第一順序

代理公司的紅利，先用於：

  1. 公司運轉；
  2. 已經承諾的設施福利。

這兩項由代理公司在賬上安排，合約不代為支付。安排之後仍有富餘，才進入積分體系。

3.2 積分：1 積分 = 1 克黃金

  • 富餘紅利由代理公司按金價記為積分；
  • 1 積分錨定 1 克黃金；
  • 記賬時查詢金價大盤，查不到就沿用上一次價格；
  • 部署時初始金價為每克 80 USDT；
  • 積分可以轉賬；
  • 代理公司也可以把積分池中的積分轉給地址。

3.3 會員消費與積分歸屬

財務上傳賬本時，會標明這筆紅利是否來自會員消費：

  • 來自會員消費，且該賬户當時持有 GCC（錢包 / 質押 / 賣單鎖定，至少 1 枚）→ 積分轉給該賬户；
  • 否則 → 積分進入積分池。

這讓“消費”與“持有”產生連接，但積分不是股權，也不是對 GCC 價格的承諾。

四、公益達成：治理權的轉換

4.1 什麼叫“達成”

當項目產出能夠覆蓋自身運轉，不必再靠持續注入分紅或股本池來維持，社區可以討論進入公益階段。

這不是一個自動觸發的合約狀態，而是需要事實、治理與公開討論的判斷。

4.2 治理怎麼變

創業期公益階段（方向）
合格質押地址一人一票1 個 KYC 賬户 = 1 票
分紅按質押數量 × 時間紅利是否發、發多少由均權投票決定
分配按票權加權方向為合資格持有人均分
代理公司主導運營社區共治 + 代理執行
股本池 / 擔保池為核心自持產能與公共品為核心

KYC 認證暫由擔保機構承擔，認證與鏈上地址映射數據公開可查。 “一人一票”要解決的是女巫攻擊與身份重複，而不是把治理變成無門檻的刷票。

4.3 公共品的六個方向

白皮書給出的方向包括：

  • 免費醫療；
  • 免費住養；
  • 榮譽激勵；
  • 科研投入；
  • 危機應對；
  • 擴大產能。

這些不是“今天已經實現的福利”，而是公益階段資金的可能去向。 具體做什麼、做多少，應由均權治理決定，並受當地法律與運營能力約束。

五、為什麼要把“轉公益”寫進規則

5.1 防止“永遠的下一次”

如果公共性只是口頭承諾，它很容易被無限期推遲。 把它寫進階段轉換，至少讓社區有一個必須討論的節點。

5.2 防止“成功後失控”

創業成功後，資本方的目標可能從“共建”轉向“套現”。 提前設計股本回贈、擔保清退與治理轉換，可以降低這種漂移。

5.3 讓公共性成為“默認選項”

當公共階段有明確的治理規則與資金方向，公益就不再依賴某個人的善意，而是成為系統的一個可選狀態。

六、這條路上仍有很多難題

難題説明
KYC 與隱私如何驗證“一人一賬户”，又不把身份數據暴露在鏈上？
女巫攻擊一個人控制多個賬户，均權投票是否會被操縱？
治理冷漠均權不等於人人蔘與，投票率低時如何避免少數人控制？
福利可持續免費醫療、住養需要長期現金流，不能只靠一次性資金
法律與税務不同司法轄區對分紅、積分、公益支出有不同要求
代理激勵公益階段代理公司如何保持運營動力？

承認這些問題，不會削弱願景；相反，它讓願景更接近可執行的制度。

七、一張階段圖

創業期
  資本進入 → 項目運營 → 利潤迴流 → 質押分紅
        │
        ▼
創業成功（條件觸發 + 投票）
  股本池回贈 → 擔保清退 → 代理繼續運營 → 積分體系
        │
        ▼
公益達成（事實 + 治理判斷）
  KYC 一人一票 → 紅利均分方向 → 醫療 / 住養 / 科研 / 危機應對
公益不是“把剩下的錢捐出去”，
而是“在賺錢之前，就決定錢最終要回到哪裏”。 PUBLIC GOOD BY DESIGN

但公益達成不是終點。當基本生存與公共服務不再吞噬大多數人的精力，價值的主戰場會從“誰擁有資本”轉向“誰能創造新的可能”。
