## 一、先定义：什么叫“向善”？

在这套设计里，资本向善不是“资本家的道德觉悟”，而是六个可观察的结果：

1. 钱进入了真实的生产与公共服务，而不是只在金融系统里空转；
2. 使用资本的人，对当地社区承担可追究的责任；
3. 创造价值的人，能按贡献与时间获得回报；
4. 失败时，有担保与清算机制，而不是让最弱的人承担全部后果；
5. 账本公开，外部可以核对，而不是只能相信叙事；
6. 成功之后，公共性有制度化的去向，而不是依赖一次性捐赠。

## 二、六个机制

### 2.1 目的锁定：先选项目类型，再谈钱

项目创建时就要选择类型：

| 类型 | 约束 |
| --- | --- |
| 全公益 | 全部收益用于公益目的 |
| 轻公益 | 运营满 10 年后退还投入，并捐献给政府 |
| 私有 | 不进路演池，仅创建者与持票人可见 |

目的锁定发生在资本进入之前。它防止“先拿钱，再决定要不要做公益”。

### 2.2 可偿还的资本：借款，而不是施舍

股本池里的 USDT 不是免费赠款，而是对持有人的兑付资金。代理公司要使用它，必须：

- 提交项目与资金规划；
- 由合格质押地址投票；
- 在链上留下借用记录；
- 用项目回馈逐步补回股本池。

这让资本有“归还”的压力，而不是一次性消耗。

### 2.3 贡献定价：1/3 补股本，2/3 按时间分

社区利润注入时：

- **1/3** 回到股本池，增厚对所有在外 GCC 的支撑；
- **2/3** 按质押数量 × 有效时长分配。

这套分配同时承认两种贡献：

- 资本提供者承担了资金占用的风险；
- 长期参与者用时间表达了承诺。

它不是“按钱分”，也不是“按人头分”，而是按“数量 × 时间”分。

### 2.4 风险共担：担保不是装饰

担保公司锁入 USDT，形成担保池：

- 创业成功时，担保价退回本人；
- 破产清算时，担保资金并入股本池，用于按机制定价兑付；
- 担保人资格有门槛：连续质押满 1 年，再锁入大于 0 的担保价；
- 担保份额只用于链下商量，不改变链上“一人一票”。

这意味着“向善”不是没有代价的。享受社区信任的主体，必须承担相应的下行责任。

### 2.5 透明：让外部可以核对

透明不是“发一份 PDF”，而是：

- 链上资金、质押、分红、投票状态可查；
- 项目树把目标、成果、任务、成本连起来；
- 代理公司的截留比例、运营成本、上链净额可对账；
- 本土货币分红由持有人自己确认，不经过代理单方面“标记已付”；
- 不提供私价市场，减少不透明的场外交易空间。

### 2.6 退出预置：成功之后去哪里

创业成功时，股本池按持有量回赠，担保清退。
公益达成后，方向转为 KYC 账户均权投票与均分制。

公共性不是“赚够钱以后再说”，而是在制度里提前写好的下一站。

## 三、一张“资本向善”记分卡

可以用下面这张表快速评估一个项目。每项 0～3 分，总分 18 分。

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
| --- | --- | --- | --- | --- |
| 目的 | 没有说明 | 只有口号 | 有项目类型 | 类型 + 可验收的公共目标 |
| 资本 | 无偿赠与 | 有口头还款 | 有借款记录 | 有投票、有归还路径 |
| 分配 | 不透明 | 只有汇总 | 有分配规则 | 数量 × 时间可复核 |
| 风险 | 无人担责 | 有担保但无约束 | 有担保池 | 有清算与追偿安排 |
| 透明 | 无可查账本 | 有内部报表 | 有公开报表 | 链上 + 链下可对账 |
| 退出 | 没有安排 | 有口头承诺 | 有书面规则 | 有合约/治理执行路径 |

::: tip 怎么用
不要用它去“评分别人”，先用它审查自己想参与的项目。
如果一项只能打到 0～1 分，先问清楚，再投入。
:::

## 四、一个项目的资本向善路径

```text
① 选类型        全公益 / 轻公益 / 私有
② 立项目        目标 → 成果 → 任务 → 成本
③ 进资本        股本借用，质押地址投票
④ 做交付        本地就业、真实产出、透明记账
⑤ 回流          1/3 补股本，2/3 按票权分红
⑥ 退出/转公益   创业成功回赠 → 公益阶段均权
```

### 每一步的“向善”检查

| 步骤 | 问什么 |
| --- | --- |
| ① 选类型 | 公共目标是否可验收？还是只有愿景？ |
| ② 立项目 | 任务是否真的服务于目标？成本是否合理？ |
| ③ 进资本 | 谁投票？借款用途是否公开？ |
| ④ 做交付 | 是否创造本地就业？是否伤害当地社区？ |
| ⑤ 回流 | 截留比例是否公开？净额是否对得上？ |
| ⑥ 退出 | 成功后公共性如何继续？失败后谁承担？ |

## 五、四个真实张力

资本向善不是“没有矛盾”，而是**把矛盾放到桌面上处理**。

### 5.1 回报 vs 公共性

资本需要回报，公共性要求让利。GCC 的处理方式是：

- 创业期承认资本的时间价值，按质押分配；
- 同时用 1/3 股本池增厚全体持有人的支撑；
- 创业成功后，把股本池回赠持有人；
- 公益阶段再转向均权与均分。

这不是一次性解决，而是分阶段处理。

### 5.2 效率 vs 共识

每个项目都投票，会慢。但不投票，资本的使用就会脱离社区。
折中方式是：**小事授权、大事投票**。当前链上只把破产、创业成功、终止代理、股本借用交给投票，其余运营交给代理公司并公开报表。

### 5.3 全球规则 vs 本地法律

GCC 试图提供一套通用规则，但代理公司必须在当地合法合规运营。
“同一套规则对所有人”不等于“同一套规则可以绕过所有司法辖区”。

### 5.4 透明 vs 隐私

账本公开不等于个人数据公开。KYC 数据应由受托机构保管，链上只保留必要的映射与结果。
透明针对的是资金与规则，不是把每个人的身份暴露在互联网上。

## 六、给项目方的六个问题

<ul class="doc-checklist">
  <li>你的项目类型是什么？公共目标如何验收？</li>
  <li>你借来的资本，具体花在哪些任务上？</li>
  <li>如果项目失败，担保与清算如何执行？</li>
  <li>你的账本能否让外部逐笔核对？</li>
  <li>你为当地创造了什么，又可能损害什么？</li>
  <li>成功之后，公共性如何继续，而不是一次性捐赠？</li>
</ul>
