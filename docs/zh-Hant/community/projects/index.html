明星項目

约 1751 字大约 6 分钟

SHOWCASE · REPLICABLE, NOT JUST IMPRESSIVE

這裏的“明星”不以估值、流量或融資額為標準，而以結構是否可複製為標準。 一個項目如果能把目標拆成成果、把成果拆成任務、把每一筆錢記清楚，它就有機會從樣板變成方法。

數據説明

以下項目與數字來自產品原型中的演示數據，用於説明項目樹、票據份額與財務口徑。 它們不代表真實融資、真實經營業績或任何收益承諾。

這些頁面結構、項目樹與鏈上面板，參考自社區 uni-app 工程（uniapp-project）中的 路演中心、任務大廳、白皮書、票據轉讓與 GCC 工作台。技術實現服務於一個目標： 讓項目的目標、任務、資金與治理關係可以被同一個界面讀懂。

一、四個樣板

01 · 農業 / 溯源 / 共治

青禾智慧農場

縣域農產品溯源與社區團購閉環，本季路演聚焦冷鏈共建。項目樹完整展示了“目標 → 成果 → 任務”的三層結構。

冷鏈共建→縣域冷鏈倉→倉租 / 製冷設備

演示口徑：總投入 128 萬元 · 640 票 · 已產生收入 35.6 萬元 · 28 名共建者 · 72% 份額已分配。

02 · 婚戀 / 輕公益

卿卿輕公益撮合

婚戀撮合服務共建池，紅娘助力與嘉賓服務收入按份額公開分賬，合規檔案與隱私分級是前置條件。

撮合服務池→成功配對→紅娘排班 / 場地

演示口徑：總投入 86 萬元 · 430 票 · 已產生收入 51.2 萬元 · 46 名共建者 · 88% 份額已分配。

03 · 能源 / ESG / 已結算

海風新能源微網

園區分佈式儲能與峯谷套利，結算批次對全體持票人公示。它展示了“重資產項目如何把結果公開到批次”。

儲能投運→儲能容量→電芯採購 / 安裝調試

演示口徑：總投入 560 萬元 · 2,800 票 · 已產生收入 192 萬元 · 21 名共建者 · 份額分配 100%。

04 · 教育 / 共識 / 低門檻

共識學堂共創

共識學會課程與線下共創活動，學費與贊助收入透明入賬。它把“知識生產”拆成可計量的課程、場地與導師任務。

課程共創→共創營→場地 / 導師酬金

演示口徑：總投入 41 萬元 · 205 票 · 已產生收入 26.7 萬元 · 58 名共建者 · 76% 份額已分配。

還有一類：高頻、輕量的社區商業

原型中還有“拾光咖啡聯盟”“鄰里互助社”“織造工坊聯營”等項目。它們共同説明：

  • 社區項目不必都是“硬科技”；
  • 小體量項目也可以通過透明的票據與任務結構建立信任；
  • “明星”不等於“最大”，而是“結構最清楚、最容易被複制”。

二、五個共同點

1. 目標可拆，不是一句口號

每個項目都從根節點開始，拆成子項目 / 目標，再拆成成果與任務。

項目（root）
├── 子項目 / 分支（branch）
│   ├── 目標（goal）
│   │   ├── 成果（outcome）
│   │   │   └── 任務（task）
│   │   └── 成果（outcome）
│   └── 目標（goal）
└── ...

這棵樹的價值不在於“好看”，而在於每一個任務都能回溯到它服務的成果，每一個成果都能回溯到項目目標。

2. 任務有成本，成本有口徑

任務支持兩種回報口徑：

  • 給票：以票權額結算；
  • 現金：以人民幣金額結算。

項目樹同時彙總計票支出、計票收入、現金支出、現金收入與計劃成本。 這讓“錢花在哪、換回了什麼”不再是一筆糊塗賬。

3. 財務可核查

項目詳情可以進入透明財務、投入明細、收入明細、票據份額與流水。 關鍵不是“有報表”，而是報表能對上：

  • 投入與票據的對應關係；
  • 任務成本與成果的對應關係；
  • 分紅 / 結算與持票人的對應關係。

4. 份額可流轉，但不是證券

原型提供票據轉讓能力，但是否可轉讓、如何定價、如何合規，必須由項目規則與當地法律共同約束。 技術上的可轉讓，不等於法律上的可發行。

5. 公共性有位置

項目類型分為：

類型含義
全公益項目全部收益用於公益目的
輕公益項目運營滿 10 年後須退還投入並捐獻給政府
私有項目不進路演池，僅創建者與持票人可見

公共性不是成功之後的“可選項”，而是在項目創建時就要選擇的類型。

三、一個樣板項目的完整讀法

以“青禾智慧農場”為例：

  1. 先看根節點：項目解決什麼問題？為什麼是冷鏈，而不是別的？
  2. 再看目標：冷鏈共建、社區團購閉環，分別對應什麼可驗證的結果？
  3. 再看成果：縣域冷鏈倉、線路開通、溯源看板，是否真的支撐目標？
  4. 再看任務：倉租、製冷設備、冷藏車、IoT 探針，每一項的成本與負責人是誰？
  5. 最後看賬：投入、收入、票權、分紅是否對得上？

如果這五步有任何一步説不清，項目就還不適合被複制。

四、從樣板到複製：六個檢查

  • 項目是否有明確的本地運營主體與合規路徑？
  • 目標是否可以拆成可驗收的成果與任務？
  • 每一項任務是否有成本口徑、負責人和完成標準？
  • 收入與分紅是否有可核查的賬本，而不是隻有彙總數字？
  • 項目類型（全公益 / 輕公益 / 私有）是否在創建時説明？
  • 如果失敗，退出、清算與責任如何安排？
明星項目不是“看起來最賺錢的項目”，
而是“最經得起被拆開看”的項目。 SHOWCASE CRITERIA
