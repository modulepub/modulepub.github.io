# spring-boot-starter-job (removed from repo)

> The `spring-boot-starter-module` aggregator **no longer includes** a standalone `spring-boot-starter-job` module. If you still need XXL-Job or similar scheduling, add dependencies in your runner or refer to an older repository revision.

Scheduling integration notes previously lived on this page; for new deployments, follow the current `tg-boot` `pom.xml` and module list.
