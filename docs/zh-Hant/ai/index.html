Starter 化能力

加依賴即裝配，減依賴即卸載。業務模塊不重複造基礎設施。

契約即邊界

跨模塊只認 *-api，接口、DTO、枚舉都和實現解耦。

AUTO 路由

本進程有實現就本地直調，沒有才走 MQ，業務代碼不變。

架構門禁

用 ArchUnit 把禁止依賴寫成測試，靠 CI 而不是靠記憶。

一鍵環境

JDK、Maven、MariaDB、Redis、Node 全部收進 .tools。

無痛拆分
